# Model Routing Rules

- **Argon (Medium/Complex)**:
  - Complex architectural refactoring and multi-file logic changes
  - Hard-to-diagnose keyboard hook, low-level Win32 API, or race condition debugging
  - Complex state management in layout switching algorithms
  - Deep design analysis and test planning

- **Flash (Fast/Small)**:
  - Small bug fixes, typo corrections, and minor config adjustments
  - Quick code reviews, searches, and file inspections
  - Building and running scripts/compilation commands
  - Fast status updates and routine tasks
